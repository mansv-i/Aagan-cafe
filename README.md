# Aangan Café · Courtyard Café Landing Page

A responsive, single-page website built with semantic HTML5, modern CSS3 (Custom Properties, Clamp Typography, CSS Grid/Flexbox), and vanilla JavaScript. 

Part of the **7 Days, 7 Websites** challenge (Day 4).

## Features
- **Real-Time Hours Status:** Dynamically checks system time against café operating hours and highlights today's schedule.
- **Interactive Menu:** Filter items by category (Chai & Brews, Courtyard Bites, Comfort Bowls, Bakery) or dietary preference (Veg-only toggle).
- **Table Reservation Form:** Client-side validated booking form with dynamic guest stepper, seat selection, and immediate feedback modal.
- **Accessible & Responsive:** Mobile-first layout with off-canvas hamburger navigation and WCAG AA contrast adjustments.

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (`Young Serif`, `Outfit`)
- No external runtime dependencies or frameworks
